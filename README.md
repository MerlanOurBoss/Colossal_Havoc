# Colossal Havoc in VR

VR-игра на Unity, в которой вы становитесь великаном и громите маленький мир: хватаете жителей и деревья, бросаете их и уворачиваетесь от снарядов пушек.

▶️ [Посмотреть геймплей на YouTube](https://www.youtube.com/watch?v=_whcceV37qI)

## Геймплей

- **Жители** ходят по маршрутам между точками патрулирования. Их можно схватить и бросить: при падении на землю житель погибает. А можно поднести ко рту и съесть.
- **Окружение** тоже интерактивное: деревья и часть объектов сцены можно брать и бросать.
- **Пушки** (3 на уровне) поворачиваются к игроку и открывают огонь, когда он видим и находится ближе 100 единиц. У каждой пушки свои скорость снарядов и интервал стрельбы.
- **Жизни:** у игрока их 4, каждое попадание снаряда в голову отнимает одну.
- **Перемещение:** телепортация по специальным зонам уровня.

## Запуск проекта

**Что понадобится**

- Unity Hub и Unity 2021.3.16f1 с модулем **Android Build Support** (нужен для сборки на шлем)
- VR-шлем: проект настроен на сборку под Android с Oculus XR Plugin (линейка Meta Quest), а для ПК подключён OpenXR

**Открытие**

```bash
git clone https://github.com/MerlanOurBoss/Colossal_Havoc.git
```

1. В Unity Hub выберите **Open** и укажите папку проекта.
2. Откройте сцену `Assets/Scenes/SampleScene.unity`.
3. Нажмите **Play** с подключённым шлемом. Для проверки без шлема в проекте есть XR Device Simulator.

**Сборка на шлем**

1. В **File → Build Settings** выберите **Android** и нажмите **Switch Platform**.
2. В **Project Settings → Player → Publishing Settings** укажите свой keystore или отключите пользовательскую подпись для отладочной сборки.
3. Включите на шлеме режим разработчика и подключите его к компьютеру.
4. Нажмите **Build And Run**.

Минимальная версия Android API — 24, целевая — 30.

## Структура проекта

```
Assets/
├── Scenes/SampleScene.unity   # основной уровень
├── Scripts/                   # игровая логика
├── Prefabs/                   # житель, снаряд, контроллеры, эффекты
├── Model/                     # модели мира, жителя и пушки
├── Materials/, Lighting/      # материалы и освещение
├── Sound/                     # звуки
├── XR/                        # настройки XR
└── Custom asstest/            # сторонние ассеты, настройки URP и XR
```

### Скрипты

| Скрипт | Назначение |
|---|---|
| `Player` | Хранит жизни игрока и обрабатывает попадания снарядов |
| `Cannon` | Наведение на игрока, стрельба, здоровье и уничтожение пушки |
| `Missile` | Столкновения снаряда с игроком и землёй, эффект взрыва, удаление |
| `EnemyHuman` | Патрулирование жителя по точкам через NavMesh |
| `HumanDeath` | Гибель жителя при ударе о землю |
| `HumanEating` | Поедание жителя при контакте с головой игрока |
| `HandPhysics` | Физическое следование рук за контроллерами (`Oculus Hands Physics`) |

Логика опирается на теги `PlayerHead`, `Player`, `GroundEarth` и `Missile`: при переносе объектов между сценами их нужно сохранять.

## Что пока не реализовано
